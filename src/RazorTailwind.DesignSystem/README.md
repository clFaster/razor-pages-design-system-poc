# RazorTailwind.DesignSystem

Reusable Tailwind-based UI building blocks for Razor Pages and MVC views.

This package includes:

- Reusable typed component models (`ButtonProps`, `BadgeProps`, `CardProps`)
- Reusable partial views in `Views/Shared/DesignSystem`
- A `NavigationMenuViewComponent` for data-driven navigation
- A `ds-container` tag helper for consistent page width
- Compiled CSS served from `_content/RazorTailwind.DesignSystem`
